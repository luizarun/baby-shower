⚙️ Turn on Live Sync
To make everyone see the same updates, connect this app to a free Google Firebase cloud (one-time, ~10 min). Follow the steps below, paste your settings into the file, then share the file. Everyone who opens it shares one live copy. 🎉
1

Create a free Firebase project

On a computer, go to console.firebase.google.com → sign in with your Google account → Add project → give it any name → skip Google Analytics → Create.

2

Add a Realtime Database

In the left menu → Build → Realtime Database → Create Database. Pick the location closest to you. Choose "Start in test mode" → Enable.

3

Register a web app

Click the gear ⚙️ → Project settings → scroll to "Your apps" → tap the </> (web) icon → give it a nickname → Register app.

4

Copy your config

Firebase shows a firebaseConfig = {…} block. Copy everything inside the braces (apiKey, databaseURL, etc.).

5

Paste it into this file

Open this HTML file in any text editor → find the line near the top of the script that says FIREBASE_CONFIG = {} → paste your settings inside the braces → Save.

6

Share & enjoy live sync

Send the saved file via WhatsApp / AirDrop. Everyone opens it in Safari and edits the same shared data — updates appear for everyone within a second! ☁️

🔒 Privacy note: Test mode lets anyone with the file read & edit the data (guest names, amounts). That's fine for sharing privately with trusted family. Only share the file with people you want editing.
🛟 Backup
Works without sync too: until you add Firebase settings, the app saves on this phone only. Charts need internet to display.
